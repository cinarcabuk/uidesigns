# Film camera UI explorations

Round 3: direction E only, in a black version and a silver version.

- Bottom controls follow the original sketch: shutter on the left, flash (Off / On / Auto) and a customizable button in the middle, camera roll on the right. Hold the custom button to choose Flip camera, Self-timer, Grid or Double exposure.
- In the silver version, the highlights on the brushed body, the chrome shutter, the black buttons and the phone frame follow device tilt. The page uses `deviceorientation` when the browser allows it and falls back to the pointer otherwise. The claude.ai artifact viewer blocks motion sensors.

Files:
- `index.html` is a standalone page. Open it on a phone over https to try the real gyro.
- `concepts.html` is the same content without the document wrapper. This is the source published as the artifact.

Earlier rounds (A–E, then the framed A, B and E) are in the git history.

## Round 4: ten new approaches (static)

`approaches.html` (artifact source) and `approaches-standalone.html` (opens in any browser) hold ten static, new interaction approaches: Waist-Level, Command Dial, Lens Barrel, Split-Image, Advance Lever, Ground Glass, Slide Switches, Keypad, Pure Finder and Grip (landscape). They are generated by `python3 tools/build_approaches.py`, which reuses the sample scene from `concepts.html`. The earlier ten E variants are in the git history.

## Round 5: ten new styles (static)

`styles.html` (artifact source) and `styles-standalone.html` (opens in any browser) hold ten static screens, each in a new visual style: Darkroom Timer, Cyanotype, Light Table, Field Camera, Toy Camera, Terminal, Enamel, Pocket LCD, Frosted Glass and Cassette. They are generated by `python3 tools/build_styles.py`.

## Round 6: glass and needle (static)

`glass.html` (artifact source) and `glass-standalone.html` (opens in any browser) hold six simple screens on a shared golden-ratio layout: Level, Drop, Cyclops and Frosted Window (liquid glass paired with analog instruments), Construction (golden-rectangle composition guide) and Command Line. They are generated by `python3 tools/build_glass.py`. The page has a toggle that shows the φ guides.
