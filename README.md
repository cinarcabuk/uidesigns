# Film camera UI explorations

Round 1: five directions (A–E) for the shooting and editing screens of an analog film-emulator camera app.

- `index.html` is a standalone page. Open it in a browser.
- `concepts.html` is the same content without the document wrapper. This is the source published as the artifact.

Every phone mock is interactive: drag shutter/ISO/± values, tap the viewfinder to spot-meter, open the mode wheel, change film, fire the shutter, and use the editor sliders, undo and redo.
